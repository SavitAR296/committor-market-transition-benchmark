# Paper 1 — Observer-induced irreversibility in trailing-window early-warning states

B. Xing and J. Pan. Prepared for submission to *Physical Review E*.

This directory is the reproducibility package of Paper 1:

- `manuscript/` — LaTeX sources of the main text, the Supplemental Material and the cover letter,
  the compiled PDFs, and the tables/figures generated by the scripts.
- `reproducibility_pre/` — the scripts, frozen result tables, figures, data and SHA-256 manifests
  that produce every number and every figure of the manuscript. See its `README_P1.md` for the run
  order, seeds and data provenance.
- `reproducibility/` — **read-only** frozen legacy package (the never-submitted single-author draft;
  see `../archive_csf_draft/` at the repository root). Paper 1's pipeline reads several frozen data
  inputs from it; it is preserved byte-identical and SHA-256-manifested.

## Quick start

```bash
cd reproducibility_pre
python -m pip install -r requirements.txt      # tested with Python 3.12.3
make -f Makefile_P1 quick    # rebuild tables/text macros/figures from frozen CSVs (~1 min)
make -f Makefile_P1 all      # full rerun of every simulation (~45 min on one core)
make -f Makefile_P1 check    # sha256sum -c SHA256SUMS_P1.txt
```

`make -f Makefile_P1 manuscript` recompiles the PDFs (requires a TeX distribution); the shipped
PDFs correspond to the shipped sources. Every result number in the text is a LaTeX macro written by
`reproducibility_pre/scripts/P1_numbers.py` from the frozen tables, with its source in
`tables_pre/P1_numbers_sources.csv`.

## Data

Third-party market data are not redistributed as raw vendor files; the frozen vega-datasets snapshot
is bundled under its license, and the 2020-2026 continuation, the VIX series and the Coin Metrics
crypto data are documented with sources, download scripts, checksums and repair records in
`reproducibility_pre/README_P1.md`.
